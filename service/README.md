# @reporook/service

Local no-code RepoRook dashboard for onboarding, security scans, plain-English findings, guided plans, and exact-proposal approval receipts.

```bash
npx --yes @reporook/service@latest --repo .
```

The service binds only to loopback and prints a private tokenized URL. It uses the `reporook` CLI for all deterministic operations and never applies application-code patches. See the repository's [service guide](https://github.com/cisoventures/RepoRook/blob/main/docs/SERVICE.md) for the complete security boundary.
